# Relatórios

| Arquivo | Quem escreve | Pra quem |
|---|---|---|
| `AAAA-Snn-semana.md` | `/semana` | uso interno do operador |
| `AAAA-MM-relatorio.md` | `/relatorio` | o cliente lê |

O semanal é rascunho de trabalho: o que saiu, o que travou, o que fazer
segunda. Pode ser cru.

O mensal vai pra mão do cliente. Escrito na linguagem dele, começando pelo
resultado — inclusive quando o resultado é queda.

Nenhum dos dois inventa número. Se o export não está em `dados/`, o campo fica
vazio e o Claude pergunta.
