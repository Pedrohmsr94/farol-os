# Saídas

Documento pontual que não é peça de conteúdo nem relatório de mês.

Proposta, escopo revisado, análise avulsa, apresentação, material que o cliente
pediu uma vez.

Peça de conteúdo vai em `conteudo/`. Relatório vai em `relatorios/`. Pesquisa vai
em `pesquisa/`. Se não é nenhum dos três, é aqui.
