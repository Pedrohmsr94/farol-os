# Diagnóstico

O retrato de onde o marketing da empresa estava quando o contrato começou.

Gerado pelo `/diagnostico`, uma vez, no início. Vira `diagnostico.md` aqui
dentro.

**Não editar depois.** Ele é a foto do dia zero — é contra ele que o resultado
do terceiro mês é comparado. O que muda a partir dali vive em
`_memoria/estrategia.md` e nos relatórios.

Se rodar de novo (contrato renovado, um ano depois), salvar como
`diagnostico-AAAA-MM.md` e manter o antigo.
