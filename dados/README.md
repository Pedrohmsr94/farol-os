# Dados

Drop zone. Joga aqui o que precisa ser lido: export de plataforma, planilha,
print, PDF, CSV de leads.

Nada dessa pasta sobe pro GitHub (menos esse README). Pode jogar dado de
cliente sem medo.

**Como nomear:** `AAAA-MM-plataforma-oquee.csv`
Ex: `2026-08-instagram-alcance.csv`, `2026-08-gmb-buscas.csv`

O `/relatorio` e o `/semana` leem daqui. Se a pasta estiver vazia no dia do
relatório, o Claude vai pedir os exports antes de escrever qualquer número —
não vai estimar.
