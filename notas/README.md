# Notas

Campanha, canal, pessoa, decisão, aprendizado. Nasce de
`templates/notas/nota.md` e é criada pelo `/fechar` ou à mão.

Nome em kebab-case minúsculo — é o nome que os `[[wikilinks]]` usam.
