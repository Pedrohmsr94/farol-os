# Pesquisa

A camada que faz o conteúdo não ser opinião solta.

| Pasta | Quem escreve | O que é |
|---|---|---|
| `fontes.md` | `/radar`, na 1ª rodada | o mapa de fontes do nicho desse cliente |
| `radar/` | `/radar` | briefings de pauta, um por rodada, mais o resumo semanal |
| `ideias/` | `/ideias` | o banco perene, um arquivo por rodada mensal |
| `angulos/` | `/angulos` | os 5 ângulos de cada tema. Os não usados viram pauta futura |
| `investigacoes/` | `/investigar` e scripts | voz real do dono, análise do nicho, comentários do público (`comentarios/`), reels de referência (`reels/`), placar da própria conta (`desempenho/`) |
| `coleta/` | `scripts/coletores/` | JSON cru de perfil e post coletado (`raw/`), com data. Matéria-prima, não leitura |
| `referencias/` | `scripts/coletores/` | mídia dos posts de referência (`midia/`, fora do git) e folha top-12 de cada perfil (`perfis/`) |
| `seo/` | `/seo` | os 7 passos, um arquivo cada |

Nada aqui é publicado. É tudo insumo — quem produz peça é `/post`, `/carrossel` e
`/publicar-tema`.

**Pesquisa velha engana.** Tudo tem data no nome ou no cabeçalho. A análise de
nicho se refaz a cada três meses; o corpus de comentários, a cada duas semanas de
uso ativo.
